# Heimdall web app

SvelteKit (Svelte 5 runes, TypeScript, Tailwind v4) single-page app. It talks to the Go server described in `../docs/api.md` and to the user's injected wallet (MetaMask, Rabby) with viem. pnpm only.

## Run

```sh
pnpm install
cp .env.example .env      # optional: PUBLIC_API_URL defaults to http://127.0.0.1:8080
pnpm dev                  # http://localhost:5173 (allowed by the server's default CORS_ORIGIN)
pnpm build && pnpm preview  # static build (adapter-static, fallback index.html), http://localhost:4173
```

`PUBLIC_API_URL` is read with `$env/static/public`, so it is fixed at build time. Change it, then rebuild.

## Checks

```sh
pnpm format && pnpm check && pnpm lint && pnpm build
```

## Notes

- `src/lib/abi/` is generated by `../scripts/gen-abi.sh`. Do not edit or reformat it (it is in `.prettierignore`).
- The expected chain id, targets, explorer and demo mode come from `GET /config`. On a chain without a public explorer (the local fork) transaction links open the app's own `/tx/[hash]` page.
- The Simulator page and nav item exist only when `/config` reports `demoMode: true`. There is no Backtest page yet (the API has no `/backtests` endpoint).
